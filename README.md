# SceneGuard

Run the community behind the roleplay.

SceneGuard is a management and safety platform for roleplay communities. It will help server owners manage staff activity, player reports, appeals, events, and security from one clear dashboard.

## Initial Features

- Staff action audit timeline
- Player reports and appeals
- Discord alerts
- Community event calendar
- Public server status page

## Development Status

SceneGuard is currently in early development.
